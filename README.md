# Kr4zy Terminal

## Introduction

Kr4zy Terminal is a lightweight and customizable desktop launcher built with Python. It helps you quickly launch applications, open websites, manage workspaces, and streamline your daily workflow through a simple terminal-like interface.

---

## Features

* 🚀 Launch applications with custom commands
* 🌐 Open websites instantly
* 📁 Workspace support
* 🎨 Customizable theme and settings
* 📝 Command history
* 🔌 Plugin support
* 🖥️ System tray integration
* ⚡ Fast and lightweight

---

## How to Run

1. Download or extract the **KrazyTerminal** folder.
2. Keep all files inside the folder together.
3. Double-click **KrazyTerminal.exe** to start the application.

> **Note:** Do not move only the `.exe` file. The application requires the accompanying files and folders to function correctly.

---

## Customization

You can customize Kr4zy Terminal by editing the JSON files included with the application.

| File              | Purpose                                       |
| ----------------- | --------------------------------------------- |
| `config.json`     | General settings (theme, colors, preferences) |
| `commands.json`   | Custom application shortcuts                  |
| `websites.json`   | Website shortcuts                             |
| `workspaces.json` | Saved workspaces                              |
| `plugins/`        | Add your own plugins to extend functionality  |

Simply edit these files with any text editor and restart the application.
